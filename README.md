# FilePeek — كاشف الملفات

يكشف FilePeek وش الماكل مساحة جهازك، ويتيح معاينة الملفات ومعرفة وش تقدر تحذفه بأمان.

FilePeek shows what is using your disk space, previews files, and helps you safely clean up.

**Windows 10 / 11 · 64-bit · عربي / English**

## التحميل

**[حمّل آخر إصدار من هنا](https://github.com/muathcodes/FilePeek/releases/latest)**

افتح صفحة الإصدار، ثم نزّل **FilePeek-Setup.exe** من قسم **Assets** وشغّل المثبّت.

## المميزات

- **فحص المساحة:** استكشف أحجام الملفات والمجلدات وحدد أكبر العناصر.
- **معاينة الملفات:** صور، فيديو، PDF، نصوص وأكواد، وملفات مضغوطة.
- **خريطة المساحة:** عرض مرئي يساعدك تفهم توزيع مساحة التخزين.
- **تصنيف الملفات:** معلومات تساعدك تميّز الملفات الشخصية وملفات البرامج والنظام.
- **التنظيف بضغطة:** راجع فئات الملفات المقترحة واختر ما يناسبك.
- **كشف الملفات المكررة:** اعرض النتائج وراجع النسخ قبل اتخاذ قرار الحذف.
- **عربي وإنجليزي:** مع وضع ليلي وجولة تعريفية.

## البداية السريعة

1. ثبّت FilePeek وافتحه، ثم اختر لغتك.
2. اختر المجلد أو القرص الذي تريد فحصه وانتظر اكتمال الفحص.
3. استعرض أكبر الملفات والمجلدات واستخدم المعاينة لمعرفة محتواها.
4. عند رغبتك بالتنظيف، راجع الملفات المحددة قبل تأكيد أي حذف.

يمكنك استخدام الفحص والمعاينة فقط دون حذف أي شيء. تصنيف الملف إرشادي؛ راجع الملفات المهمة واحتفظ بنسخة احتياطية منها.
