## Features

- ⚡ **Fast disk analysis:** Explore drives and folders and find your largest files. Scan speed varies with the drive, file count, and access permissions.
- 🎨 **Color classifications:** Safe to delete, personal, needed by an app, or a system file — with explanations to help you decide.
- 👁️ **Built-in previews:** Preview images, text, and documents, and play video and audio with a click.
- 📖 **Understand your files:** See file-type information, the associated app, and a Wikipedia summary when an internet connection is available.
- 🧹 **One-click cleanup:** Review caches, temporary files, and logs before cleaning.
- 🗂️ **Explore your storage:** Find duplicate files and forgotten folders, and visualize disk usage with the space map.
- 🎮 **Windows tools: apps, games, startup & notifications.**
- ↩️ **Deletion history and recovery:** Track operations and restore files that remain available in the Recycle Bin.
- 🔔 **Low-space alerts:** Get notified when a drive is running low on space.
- 💬 **Offline assistant:** Get answers to usage questions without internet access; retrieving Wikipedia information requires a connection.
- 🌐 **Arabic & English interface:** Switch between languages and light or dark themes.

File classifications are guidance. Review file contents before deleting and keep backups of important files. You can scan and preview files without deleting anything.

## Requirements

- **Windows 10 or 11 — 64-bit**
- **Arabic & English interface**, with light and dark themes.

Download **FilePeek-Setup.exe** from **Assets** on the release page.

## Installation

1. Open the [latest release page](https://github.com/muathcodes/FilePeek/releases/latest).
2. Download **FilePeek-Setup.exe** from **Assets**.
3. Run the installer and follow the instructions.
4. Open FilePeek, choose Arabic or English, then select a folder or drive to scan.

**Windows note:** On first launch, Windows may display a blue SmartScreen warning: **More info → Run anyway**. Use the installer downloaded from this repository’s release page.

### المميزات

- ⚡ **فحص سريع للمساحة:** استكشف الأقراص والمجلدات واعرف أكبر الملفات. تختلف السرعة بحسب القرص وعدد الملفات وصلاحيات الوصول.
- 🎨 **تصنيف بالألوان:** آمن للحذف، شخصي، مهم لبرنامج، أو ملف نظام — مع شرح يساعدك على اتخاذ القرار.
- 👁️ **معاينة داخل البرنامج:** صور ونصوص ومستندات، وتشغيل فيديو وصوت بضغطة.
- 📖 **افهم ملفاتك:** معلومات عن نوع الملف والبرنامج المرتبط به، مع نبذة من ويكيبيديا عند توفر اتصال بالإنترنت.
- 🧹 **تنظيف بضغطة:** مراجعة الكاش والملفات المؤقتة والسجلات قبل التنظيف.
- 🗂️ **استكشف التخزين:** كشف الملفات المكررة، والمجلدات المنسية، وخريطة المساحة.
- 🎮 **أدوات ويندوز: التطبيقات والألعاب والتشغيل التلقائي والإشعارات.**
- ↩️ **سجل الحذف والاسترجاع:** متابعة العمليات وإمكانية الاسترجاع للملفات المتاحة في سلة المحذوفات.
- 🔔 **تنبيهات المساحة:** إشعار عند انخفاض مساحة القرص.
- 💬 **مساعد محلي:** يجيب عن أسئلة الاستخدام دون إنترنت؛ جلب معلومات ويكيبيديا يحتاج اتصالًا.
- 🌐 **عربي وإنجليزي:** مع وضع نهاري وليلي.

تصنيف الملفات إرشادي؛ راجع المحتوى قبل الحذف واحتفظ بنسخة احتياطية من الملفات المهمة. يمكن استخدام الفحص والمعاينة دون حذف أي ملف.
